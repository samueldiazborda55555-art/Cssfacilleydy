Box Model

¿Qué es el Box Model?

El Box Model es una de las bases fundamentales para entender cómo se comportan los elementos en una página web. Si alguna vez te has preguntado por qué un botón no se alinea como esperas o por qué un div tiene más espacio del que debería, el Box Model tiene la respuesta.

Imagina que cada elemento HTML es una caja. Esa caja no es solo el contenido que ves: está compuesta por varias capas que definen su tamaño y su espacio en la página.

  • Content (contenido): donde se muestra el texto, las imágenes u otros medios.
  • Padding (relleno): el espacio entre el contenido y el borde.
  • Border (borde): el límite que rodea el padding y el contenido.
  • Margin (margen): el espacio exterior que separa el elemento de otros.

Content y Padding

El content es el área donde se muestra el texto o las imágenes. Su tamaño se controla con width y height.

El padding es un colchón invisible entre el contenido y el borde. 

padding: 10px 20px;

Border y Margin

El border es la línea que rodea el padding y el contenido. 

border: 2px solid black;

El margin es el espacio exterior que separa un elemento de otros. 

margin: 10px 20px;

Box sizing

Controla cómo se calcula el ancho y el alto de un elemento.

content-box (por defecto): el padding y el borde se suman al tamaño total. Con width 200px, padding 20px y borde 5px, el total es 250px.

border-box (recomendado): el padding y el borde quedan dentro del tamaño definido. 

* {
    box-sizing: border-box;
}
Formularios

Cada campo de un formulario es una caja: tiene contenido, padding, borde y margen. Con border-box el padding y el borde no cambian el ancho total del campo. 

.form-input {
    box-sizing: border-box;
    width: 100%;
    padding: 12px;
    border: 2px solid #ddd;
}
Técnicas útiles

Margen negativo: permite superponer elementos. 

margin-top: -20px;

Overflow: decide qué pasa cuando el contenido es más grande que su caja (hidden, scroll, auto o visible).

Debugging

Añade un borde y un fondo semitransparente para ver la estructura de tus elementos. 

.debug {
    background: rgba(255, 0, 0, 0.1);
    border: 1px solid red;
}

También puedes inspeccionar cualquier elemento con las DevTools del navegador para ver su Box Model.

Mejores prácticas
  • Usa un reset CSS con box-sizing: border-box.
  • Usa unidades relativas (%, em, rem) en lugar de solo px.
  • Mantén un espaciado consistente.
  • Usa min-height en lugar de alturas fijas.
Problemas comunes
  • Desbordamiento: usa overflow: auto;.
  • Altura del 100%: el contenedor padre debe tener una altura definida.
  • Floats: usa clear: both; o un clearfix.
  • Colapso de márgenes: cuando dos márgenes verticales se tocan, pueden colapsar en vez de sumarse. Usa padding o Flexbox con gap.
